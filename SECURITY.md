# Security

pydelhi.org is a static site: Eleventy builds it into plain HTML, CSS and JavaScript, and GitHub Pages serves it. There are no accounts, forms or databases on the site itself.

## Reporting a problem

If you find a security problem, such as a way to change what the site shows, a leaked secret in this repo or its build, or a vulnerable dependency that affects the build, email **[contact@pydelhi.org](mailto:contact@pydelhi.org)** instead of opening a public issue.

Tell us what you found, how to reproduce it, and what you think the impact is. We're volunteers, but we'll reply as soon as we can and keep you posted while we fix it.

## Not in scope

Services the site only links to, like Commudle, WhatsApp, Telegram, Google Forms and GitHub itself. Report problems there to those services.
