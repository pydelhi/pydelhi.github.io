# Code of Conduct

This repo follows the **PyDelhi Community Code of Conduct**, the same one that covers our meetups, chats and mailing list. The full text is at **[pydelhi.org/coc](https://pydelhi.org/coc/)**, and its source is [`src/coc.md`](src/coc.md).

It applies everywhere the community meets, including issues, pull requests, reviews and discussions on GitHub.

## In one breath

Be friendly. Be patient. Ask when you're unsure. Disagree without attacking anyone. And if someone asks you to stop, stop.

## Reporting

You don't have to deal with it alone. Email **[contact@pydelhi.org](mailto:contact@pydelhi.org)**. You can also reach the organisers on [Telegram](https://t.me/PyDelhi_official) or [LinkedIn](https://www.linkedin.com/company/pydelhi-community/), or talk to any PyDelhi volunteer at a meetup.

We'll listen, keep it confidential, and act on it. Please don't report Code of Conduct problems in a public issue.
